# 🐱 Adote um Amigo - Adoção de Pets

**Categoria:** Pet
**Tipo de projeto:** `catalogo_filtro`

Galeria de animais com filtro de espécie/porte.

## 🎯 Conceitos abordados
- Estrutura HTML semântica (`header`, `section`, `article`, `footer`)
- Meta tags, acessibilidade básica e SEO
- CSS moderno: variáveis, Flexbox, Grid, transições, media queries
- Layout responsivo (mobile-first)
- JavaScript: manipulação do DOM, eventos, validação de formulário
- Filtro dinâmico de listas com JavaScript


## 📂 Estrutura de arquivos
```
18-adocao-pets/
├── index.html      # estrutura da página
├── styles.css      # estilos e responsividade
├── script.js       # interatividade
└── README.md       # este arquivo
```

## ▶️ Como executar
Basta abrir o arquivo `index.html` em qualquer navegador moderno.
Não precisa de servidor — é HTML, CSS e JavaScript puro.

## 💡 Exercícios de fixação sugeridos

1. Adicionar um campo de **busca por texto** (`input` + `filter`).
2. Implementar **ordenação** por preço/nome (asc/desc) com `array.sort()`.
3. Adicionar mais 5 itens ao array e uma nova categoria.
4. Salvar o filtro ativo no `localStorage` e restaurar ao recarregar.
5. Trocar os emojis por imagens reais (`<img>`).
6. Carregar os dados de um arquivo `dados.json` usando `fetch`.
7. Criar paginação (mostrar 4 itens por página com botões anterior/próximo).
8. Animar a entrada dos cards com `transition` + `opacity`/`transform`.
